Dokumentasi & Implementasi Proyek

Fleet Management System (FMS) "Senopati"

Perancangan infrastruktur server, pengujian lapangan, pelatihan karyawan, hingga tahap *go-live* untuk sistem Fleet Management System (FMS) bernama Senopati di PAMA Kide Site Batukajang.

Alur Pemantauan Unit (Mining Tracking Workflow):
  1. Pit Stop / Standby: Unit melakukan persiapan, pengecekan awal, dan siap memasuki siklus kerja tambang.
  2. Loading (Muat): Unit pengangkutan menuju front tambang untuk proses pemuatan material oleh Excavator/Loader.
  3. Hauling (Angkut): Pergerakan ritase unit angkut (*Dump Truck* / HD) menyusuri jalur *hauling road*.
  4. Dumping (Bongkar Muat): Unit tiba di stockpile atau disposal untuk melakukan pembongkaran material secara terpantau.

Tahapan Implementasi Proyek:
• Infrastruktur & Server: Perakitan, instalasi OS/layanan, serta perapian kabel rak server utama.
• Trial Lapangan: Pemasangan dan kalibrasi perangkat keras FMS pada unit kendaraan tambang.
• Pembimbingan & Training: Transfer pengetahuan dan pelatihan operasional kepada karyawan & tim lapangan.
• Go-Live & Monitoring: Pengawalan penuh hingga sistem beroperasi aktif di ruang kontrol.

MOSENTO (Monitoring Kesehatan Unit Otomatis)

Pengembangan sistem VHMS Check otomatis bernama MOSENTO saat bertugas di PT. Bina Sarana Sukses (BSS). Mencakup perakitan perangkat, uji coba, hingga meeting penentuan parameter monitoring data.

Alur Kerja Sistem (Workflow):
  1. Unit (HD/Dozer/Excavator): Mengirimkan data kesehatan unit secara otomatis setiap kali mendeteksi Access Point (AP).
  2. Server Sementara: Menampung dan memproses data dari lapangan di area site.
  3. Internet & Server Utama: Data disinkronkan melalui internet dan disimpan terpusat di Server Utama.
  4. User / Dashboard: Tim dapat langsung memantau kesehatan seluruh unit secara real-time dari ruang kontrol.

Tahapan & Cakupan Proyek:
• Meeting & Analisis: Diskusi tim untuk merumuskan parameter data kesehatan unit yang krusial.
• Perakitan & Rangkaian: Perakitan modul mikrokontroler/perangkat keras VHMS check.
• Trial & Pengujian: Uji coba fungsionalitas sistem secara mendalam.
• Implementasi Unit: Integrasi dan pengujian langsung pada unit-unit alat berat di lapangan.

Fuel Management System (FMS)

Pengembangan sistem manajemen bahan bakar terintegrasi (Fuel Management System) mulai dari perakitan perangkat keras, *development* sistem, hingga implementasi dan *go-live* yang diaplikasikan dan digunakan di berbagai site operasional.

Alur Proses Pengisian BBM (RFID Fuel Workflow):
  1. Tab RFID (Identifikasi Driver): Driver melakukan tap kartu RFID pada reader untuk memvalidasi identitas nama driver dan NRP secara otomatis.
  2. Proses Pengisian (Dispensing): Setelah data driver terverifikasi oleh sistem, proses pengisian bahan bakar ke unit alat berat dimulai.
  3. Pencetakan Struk (Printing): Mesin secara otomatis mencetak struk/nota pengisian yang memuat detail volume bahan bakar, waktu, serta informasi driver.
  4. Penyimpanan Database (Logging): Seluruh data transaksi pengisian tersimpan secara otomatis dan terpusat ke dalam database untuk kebutuhan auditing.

Tahapan & Cakupan Proyek:
• Perakitan Hardware: Perakitan komponen kontroler, panel, dan wiring sistem ukur bahan bakar.
• Software & Development: Pengembangan sistem dan integrasi modul pencatatan data BBM.
• Deployment & Go-Live: Pemasangan di lapangan dan penerapan operasional yang sukses digunakan di berbagai site.

Speed Awareness Monitor (SAM)

Sistem pemantauan dan peringatan batas kecepatan kendaraan (Speed Awareness Monitor) yang dikembangkan saat bertugas di PT. Satnetcom untuk meningkatkan keselamatan operasional di area tambang.

Alur Kerja Sistem (SAM Workflow):
  1. Deteksi Radar: Perangkat memancarkan sinyal radar untuk mendeteksi kecepatan unit yang melintas.
  2. Peringatan Overspeed: Jika melebihi batas, papan indikator LED menyala memperingatkan pengemudi.
  3. Snapshot & Storage: Kamera otomatis merekam video/foto pelanggaran dan menyimpannya ke memori lokal.
  4. Remote Host Sync: Data dikirim via Wi-Fi/GPRS ke ruang kontrol untuk analisis dan pengunduhan data (*Full Data Download*).

Cakupan Teknologi & Peran:
• Integrasi sensor radar kecepatan dengan display LED dot-matrix.
• Pemasangan kamera pengawas industri (Axis) untuk validasi visual *overspeed*.
• Konfigurasi sistem catu daya surya mandiri dan jaringan nirkabel di site pertambangan.

Timbangan Otomatis (SAM vs PKS)

Pengembangan sistem timbangan otomatis terintegrasi di PT. HARUMAgro / PT. Sumatra Agro Mandiri (SAM). Berperan penuh sebagai Developer sekaligus Quality Control (QC) dari perancangan *hardware* hingga *software*.

Fitur & Alur Sistem Timbangan Otomatis:
  1. Capture Otomatis & Data Timbang: Perekaman data kendaraan (No. Plat, Supir, Afdeling, Komoditi) serta penangkapan foto visual (*capture*) kamera atas saat timbang masuk dan keluar.
  2. Kalkulasi Otomatis (Tara, Bruto, Netto): Perhitungan berat bersih secara presisi, jumlah janjang, serta BJR (Berat Janjang Rata-rata).
  3. Audit Rekonsiliasi (SAM vs PKS): Pembandingan data penimbangan di stasiun SAM dengan data Pabrik Kelapa Sawit (PKS) untuk mengontrol selisih berat (*shrinkage/variance*) dan durasi waktu perjalanan.
  4. Real-time Reporting: Pengiriman rekapitulasi laporan transaksi penimbangan otomatis langsung ke perangkat seluler (*Real-time WhatsApp Notification*).

Cakupan Tanggung Jawab (Full-Stack & QC):
• Hardware Integration: Integrasi jembatan timbang, sensor, dan kamera pengawas sudut atas (*top-view camera capture*).
• Software Development: Pembuatan aplikasi pencatatan, kalkulasi otomatis, dan modul sinkronisasi data lintas lokasi (SAM & PKS).
• Quality Control (QC): Pengujian ketat akurasi timbangan, stabilitas sistem, dan validasi keluaran laporan data operasional.
